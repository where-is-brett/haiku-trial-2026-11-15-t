# Does REF mark a refund on the bank statement, or just a reference number?

- **Date:** 15 November 2026
- **Piece:** refund-shows-as-spending
- **Options:** A. Only rows marked REFUND are money back (recommended) (A refund that is written only as REF with a number stays spending; Can be undone) · B. Also rows with REF and a number are money back, as you chose (Bills and purchases with a reference number count as money back, so totals are wrong; Can be partly undone)
- **Recommended:** refund-only
- **Chosen:** refund-only
- **The director's words:** none
